COMMENT /* THIS MODULE PRESETS THE MODULES ON A SPECIFIC BIU TO "OK" UPON POWER

APPROPRIATE MODULE'S BIT WILL BE CLEARED INDICATING A FAULT CONDITION
EXISTS ON THE MODULE. IF A BIU'S DEVICE ACTIVE BIT IS NOT DETECTED AS 
ACTIVE THIS MODULE WILL FORCE ALL MODULES ON THE BIU AS FAILED. 

THIS MODULE USES REGISTERS 5850 -5899. %T'S 1-33, %M'S 257-528


SET UP PROCEEDURE:

- SET THE MASKS BEFORE THE THREE MATRIX COMPAIRS RUNGS 9, 21 AND 29.THEY
  SHOULD BE THE SAME BITS SET IN BOTH MASKS.  SEE COMMENTS THERE

  TESTED APPEAR IN RUNG 47.  LOWEST FIRST THEN HIGHEST IN THE CONST AREA. */;	END_RUNG;
